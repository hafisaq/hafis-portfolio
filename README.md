# Hafis Portfolio

First version of a mobile-first portfolio OS built with Vite, React, TypeScript, Tailwind CSS, and Motion.

## What is included

- Premium portfolio OS landing experience
- Command-palette navigation with keyboard shortcut support
- Mobile bottom dock workspace navigation
- Project, story, resume, and contact workspaces
- Reduced-motion support
- Lazy-loaded workspace surface
- Lightweight custom SVG/CSS visual system with no Three.js dependency

The transparent MOV memoji asset was not added in this pass because `/mnt/data/aw.MOV` was not available in the local environment. The hero is structured so a converted WebM/MP4 asset can be added later without changing the app architecture.

## Local development

```bash
npm install
npm run dev
```

## Checks

```bash
npm run lint
npm run build
```
